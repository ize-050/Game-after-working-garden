# เก็บดีไซน์ตาม Stitch — 22 กันยายน 2026

อัปเดตภายหลังในวันเดียวกัน: full iOS app build และเปิดหน้าสวนบน iPhone 17 / iOS 26.3.1 Simulator สำเร็จแล้ว ดู [ภาพจาก Simulator](verification/build/screenshots/ios-simulator-farm.png) และ [ผลรันล่าสุด](SETUP-STATUS.md) ขอบเขตตรวจด้านล่างเป็นบันทึกตอนทำ design parity ไม่ใช่การรับรองทุกระบบบนมือถือจริง

อ้างอิง [Stitch ฉบับเกมปลูกผัก](https://stitch.withgoogle.com/projects/11043770835758050762) และ [PRD](../PRD.md)

รอบนี้แก้ shared Compose ของเกมจริง ไม่ใช่ HTML mockup และไม่เปลี่ยน game engine, save schema หรือเซฟของผู้เล่น การทดสอบทั้งหมดใช้เซฟแยกใน harness

## รูปต้นฉบับและข้อแตกต่างที่ตั้งใจรักษา

- URL และขนาดภาพอยู่ใน `design/stitch-assets.json` ภาพ welcome/village/shopkeeper/carpenter/market นำมาจาก URL ที่อ่านได้ในเอกสารหน้าจอ Stitch ของโปรเจกต์นี้
- ตัดภาพเพื่อจัดกรอบเฉพาะตอนวาดด้วย Compose ไม่แก้ไบต์ของต้นฉบับ ตัวเลข ชื่อ และปุ่มเกมเป็น native UI
- ภาพผักตัวอย่างมีราคาและหัวข้อฝังอยู่ จึง **ไม่** ใช้เป็นป้ายราคาของจริง เช่น ผักกาดในภาพราคา 50 แต่ PRD ขาย 18 เหรียญ
- ภาพฟาร์มล่าสุดใน Stitch ดึงได้เป็น HTML ไม่ใช่ไฟล์ภาพ จึงยังใช้ `farm_backdrop.png` เดิม ไม่แอบแทนแปลงผักที่เปลี่ยนสถานะได้ด้วยภาพนิ่ง
- กติกาอ้าง PRD: 1 เมล็ด→1 ผลผลิต, โต 2/5/10/20 นาทีหลังรดครั้งแรก, ขยายแปลง 180, บัวใหญ่ 150; ไม่ใช้จำนวน/เวลา/โบนัสตัวอย่างที่ไม่ตรงกันระหว่างหน้าของ Stitch
- ภาพตัวละคร/ฉากต้นฉบับผสมกับไอคอน แปลง และผักที่วาด native; **ยังไม่ใช่ pixel-identical ทั้งเกม** ภาพต้นฉบับบางชิ้นมีความละเอียดต่ำ และช่องไฟปรับตามจอเล็ก/ข้อความไทย/ข้อมูลบัญชีที่เพิ่มจริง
- หน้าร้าน/งาน/อัปเกรดยาวกว่าหนึ่งจอ เลื่อนอ่านและซื้อได้ ไม่ย่อข้อความและพื้นที่กดจนอ่านหรือแตะยาก

## การตรวจ

คำสั่งสำหรับทดสอบและสร้างภาพจาก shared UI:

```sh
./scripts/gradle.sh -p verification jvmTest smokeUi renderScreens --offline --no-daemon --console=plain '-Dorg.gradle.jvmargs=-Xmx1g -Dfile.encoding=UTF-8'
```

ชุดใหม่ใน `DesignParitySmoke.kt` ตรวจตำแหน่ง 6 แปลงและเครื่องมือที่ 320dp, การเลือกแปลงแรก, รดหนึ่งแปลง/ทั้งหมด, ปุ่ม disabled, เริ่มใหม่ยกเลิก/ยืนยัน, ตั้งค่าจากหน้าแรก, เงินขาด 60/30 เหรียญ, ซื้ออัปเกรดครั้งเดียว และทางไป–กลับร้านทั้งสี่จากแผนที่ ส่วน `MvpUiSmoke.kt` เพิ่มการตรวจใบรับเงินและยอดขายที่เปลี่ยนหลังแต่ละรายการ

ผลล่าสุด: **75 unit tests + UI smoke ผ่าน**, JVM build 2m04s; iOS Kotlin compile ผ่าน 25s ไม่ใช่การ link `.app` หรือทดสอบอุปกรณ์

ภาพรวม **36 PNGs**: 13 หน้า/สถานะ × 2 ขนาด และภาพหลังเลื่อนจริงไปท้ายหน้าร้าน/ตลาด/งาน/อัปเกรด/ตั้งค่าอีก 10 ภาพ อยู่ใน `verification/build/screenshots/` แกลเลอรี `preview/index.html` เป็น **ภาพจาก Compose ไม่ใช่เว็บเกมที่เล่นได้** ไม่ได้เปิด HTTP server ในรอบนี้ เปิด PNG ใน Codex ได้โดยตรง ผลรันสุดท้ายบันทึกใน [SETUP-STATUS.md](SETUP-STATUS.md)

## ยังไม่ใช่การรับรองเกมพร้อมเผยแพร่

- ตรวจ Simulator runtime วันที่ 22 กันยายน: ยังว่าง จึงยังไม่ยืนยัน safe area, touch, เสียง, persistence หรือ auth บน iPhone จริง
- Firebase ยังไม่ได้สร้าง/configure; ไม่มี real Google/Apple login, cloud integration test หรือการ deploy ในรอบนี้
- ไม่มีการชำระเงินจริง ฤดูกาล สัตว์เลี้ยง คราฟต์ งานรายวันต่อเนื่อง หรือระบบเลเวลเต็ม สิ่งเหล่านี้ไม่ใช่ส่วนที่เสร็จเพียงเพราะหน้าจอถูกจัดใหม่
