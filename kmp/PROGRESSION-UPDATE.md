## 2. งานเพื่อนบ้านต่อเนื่อง

มีคำขอ 10 แบบหมุนเวียนจากคุณยาย พี่ต้น ป้าพร และน้องเมย์ ส่งครบแล้วแสดงงานถัดไปทันที ไม่มี deadline และไม่เสียค่าข้ามวัน งานปัจจุบันผูกกับจำนวนงานที่ส่งแล้ว จึงไม่เปลี่ยนเองเมื่อเลเวลเพิ่ม งานแรกยังเป็นผักกาด 2 ต้น รับ 45 เหรียญ / 20 XP และงานต่อไปเป็นแครอต 2 ต้น

## 3. แต่งสวน

ซื้อด้วยเหรียญในเกมเท่านั้น: รั้วไม้ 80, ทางเดินหิน 65, โคมไฟ 110, ม้านั่ง 140, สีบ้านมิ้นต์หรือพีชอย่างละ 120 ซื้อครั้งเดียวแล้ววาง/เก็บกลับได้ฟรี ไม่มีการขายคืน ของแต่งใช้จุดวางตายตัว 5 จุด ไม่ใช่ระบบลากวางอิสระ บ้านและของแต่งที่เลือกปรากฏในภาพสวนจริง และมี preview ก่อนซื้อ

## 4. สมุดสะสมพืช

นับผลผลิตที่เก็บเกี่ยวแต่ละชนิดตลอดอายุสวน ไม่ลดลงเมื่อขายหรือส่งงาน แต่ละพืชมีตรา 10 และ 50 ต้น ให้รั้วดอกไม้และโคมดาวอัตโนมัติ ของรางวัลชนิดเดียวกันไม่เพิ่มซ้ำ เปิดสมุดได้จากฟาร์มหรือกระเป๋า

เซฟรุ่นเก่าไม่มีประวัติการเก็บเกี่ยว จึงเริ่มนับสถิติใหม่นับจากอัปเดต ไม่เดาจำนวนจากผักในกระเป๋าหรือเพิ่ม XP ย้อนหลัง

## 5. แมวประจำสวน

ตั้งชื่อได้ไม่เกิน 24 ตัวอักษร ลูบหัวเพิ่มความสนิทครั้งละ 1 โดยเว้นอย่างน้อย 60 วินาทีจริง ไม่ใช้เวลาเดโม แมวปลดล็อกท่าเคลิ้มเมื่อสนิท 5 และกลิ้งอ้อนเมื่อสนิท 15 ไม่มีค่าอาหาร ไม่มีวันหมดอายุ และไม่ลดความสนิทเมื่อพักเกม

## 6. แจ้งเตือนรวมแบบเลือกเปิด

ปิดไว้เป็นค่าเริ่มต้น เปิดได้จากตั้งค่าและขอสิทธิ์ระบบเฉพาะเมื่อเลือกเปิด เป็น local notification ไม่ใช้ push server หรือ token ตั้งรอเพียง 1 รายการสำหรับสวนที่ใช้งาน โดยรอให้พืชที่กำลังโตในรอบนี้พร้อมทั้งหมดแล้วบอกจำนวนรวม

การปลูก/รดน้ำ/เก็บ/เปลี่ยนสวนจะคำนวณรายการใหม่ ปิดตัวเลือกหรือมีปัญหาเซฟ/บัญชีจะยกเลิกรายการเก่า ไม่แจ้งย้อนหลังให้ผักที่โตแล้วตอนเปิดแอป การส่งจริงขึ้นอยู่กับสิทธิ์ notification, Focus และการประหยัดพลังงานของ OS โดยเฉพาะ Android ไม่ขอสิทธิ์ exact alarm

iOS ใช้ `UNUserNotificationCenter` กับ one-shot trigger และ identifier เดียว ยกเลิกรายการของเกมเท่านั้น; Android ใช้ inexact `AlarmManager.set` + `PendingIntent` เดียว เก็บ fingerprint และคืนรายการที่ยังเป็นอนาคตหลัง reboot ไม่สร้างการแจ้งเตือนรายแปลงหรือซ้ำเมื่อเปิดแอปกลับมา การปิดแอปตามปกติไม่ยกเลิก reminder ที่เลือกเปิดไว้ แต่การ force-stop/ข้อจำกัดแบตเตอรี่ของระบบอาจหยุดหรือชะลอการส่งได้ การเปลี่ยนสวนจากอุปกรณ์อื่นยังไม่เป็นที่รู้จักจนกว่าเครื่องนี้จะซิงก์

อ้างอิง API ทางการ: [Apple local notification center](https://developer.apple.com/documentation/usernotifications/unusernotificationcenter), [Apple one-shot time trigger](https://developer.apple.com/documentation/usernotifications/untimeintervalnotificationtrigger), [Android runtime notification permission](https://developer.android.com/develop/ui/compose/notifications/notification-permission), [Android inexact alarms](https://developer.android.com/develop/background-work/services/alarms). Android อาจส่งช้ากว่าเวลาเติบโต จึงไม่แสดงว่าเป็น alarm ตรงวินาที

ตรวจ syntax ของ Swift notification adapter และ host ที่แก้ด้วย `swiftc -frontend -parse` ผ่าน; `plutil -lint` ของ Xcode project/Info.plist ผ่าน นี่ไม่ใช่การ type-check/link กับ Shared framework รุ่นใหม่หรือการทดสอบการส่งจริงบน iPhone ส่วน Android source ยังไม่ compile เพราะ SDK ยังไม่พร้อม

รายการตรวจบนมือถือจริงก่อนเปิดให้ผู้เล่นใช้:

- ติดตั้งใหม่: ไม่มี dialog เอง; เปิดตัวเลือกแล้วเลือกอนุญาต/ปฏิเสธ/ปัด dialog ทิ้ง จากนั้นกลับเกมได้
- รดน้ำหลายแปลงเวลาไม่เท่ากัน ปิดแอป แล้วได้รับไม่เกิน 1 รายการเมื่อแปลงสุดท้ายพร้อม; แตะรายการเปิดเกมได้
- ปิดตัวเลือก เปลี่ยนบัญชี เริ่มสวนใหม่ หรือเจอ conflict แล้วรายการเก่าต้องไม่แจ้งผิดสวน
- ปิดสิทธิ์จาก OS settings แล้วกลับเข้าแอป: แสดงสถานะจริงและไม่แกล้งแสดงว่าตั้งสำเร็จ; เปิดสิทธิ์ใหม่แล้ว reconcile ได้
- Android: reboot ก่อนกำหนดต้องคืนรายการอนาคตเดิม, reboot หลังครบเวลาไม่ replay; ทดสอบ Doze และ force-stop แล้วเปิดเกมกลับมาเพื่อจัดตารางใหม่
- iOS: ตรวจ background/terminated, Focus/silent mode และการยกเลิกใกล้ถึงเวลาส่ง; ตรวจว่าเปิดแอปหลังผักพร้อมแล้วไม่ส่งซ้ำ

## เซฟและความปลอดภัย

- เซฟ schema 2 เก็บจำนวนงาน สถิติพืช ของแต่งที่ซื้อ/เลือก และแมว
- อ่าน schema 1 แล้วเติมข้อมูลใหม่โดยคงเหรียญ XP เมล็ด ผลผลิต แปลง อัปเกรด และเวลาเดิม ถ้าส่งงานคุณยายแล้วจะไปงานที่ 2
- ตรวจข้อมูลผิดรูป จำนวนติดลบ และ overflow; กติกาล้มเหลวไม่หักเงิน/ผลผลิต
- การตั้งค่าแจ้งเตือนอยู่เฉพาะเครื่อง แยกจากเซฟสวนและการซิงก์บัญชี
- ยังใช้เวลาจากเครื่อง ไม่มีระบบป้องกันโกงหรือเศรษฐกิจร่วมผู้เล่น

ทดสอบเส้นทางซื้อ/วาง/เก็บของแต่ง ล็อกพืชตามเลเวล เก็บเกี่ยวจนเลเวลเพิ่มและได้ตรา 50 ส่งงานต่อเนื่อง กัน double-tap ส่งงานถัดไปโดยไม่ตั้งใจ เปลี่ยนชื่อแมว ลูบหัว/cooldown/เปิดเซฟใหม่ และการเข้าหน้าสมุด/แจ้งเตือน สร้างภาพ Compose 17 หน้าจอ/สถานะ × 2 ขนาด (393×852, 320×640) พร้อมภาพหลังเลื่อนอีก 16 ภาพ รวม 50 ภาพ ตรวจภาพหน้าระบบใหม่และแก้สัดส่วน scene แล้ว

ยังไม่ได้ rebuild native binary v0.2: พื้นที่เครื่องประมาณ 4 GiB ต่ำกว่า guard 5 GiB; แอปใน Simulator ยังเป็นรุ่นก่อนอัปเดต Android ยังไม่มี SDK และ local notification ยังต้องผ่าน checklist มือถือจริงด้านบน ไม่ดาวน์โหลด SDK หรือลบข้อมูลผู้ใช้ในรอบนี้

ชุดทดสอบใช้เซฟแยก ไม่แตะสวนบน Simulator หรือมือถือ ภาพเป็น shared Compose จริงใน JVM ไม่ใช่หลักฐานการส่ง notification ของ OS บนมือถือ ต้องตรวจการอนุญาต/ปฏิเสธ/ปิดสิทธิ์ภายหลัง แอป background และ reboot บนอุปกรณ์จริงก่อนเผยแพร่
