# MVP completion pass — 21 September 2026

เติมช่องว่างของต้นแบบตาม PRD ไม่เปลี่ยนราคาเมล็ด ราคาขาย เวลาเติบโต หรือเพิ่มระบบเล่นระยะยาวนอกขอบเขตรอบนี้

## เพิ่มแล้ว

- ร้านเมล็ดและตลาด: เพิ่ม/ลดจำนวน แสดงยอดรวมก่อนยืนยัน ยอดเหรียญที่ขาดจริง ปิดปุ่มเมื่อของ/เงินไม่พอ ป้องกันจำนวนและยอดเงินล้น และเริ่มจำนวนที่ 1 หลังสำเร็จ
- เลือกจำนวนอย่างเดียวไม่ตัดของ/เหรียญหรือเขียนเซฟ ทุกธุรกรรมตรวจข้อมูลล่าสุดอีกครั้งตอนกด
- ร้านจำแปลงต้นทาง กลับมาเปิดเลือกเมล็ดที่แปลงเดิมได้; ตรวจซ้ำว่าแปลงยังว่างพร้อมปลูก และล้างบริบทเมื่อเปลี่ยนบัญชีหรือเริ่มสวนใหม่
- หน้าปลูกแสดงหมายเลขแปลง เวลาเติบโต จำนวนเมล็ด และราคาขาย; ตะกร้าว่างมีทางกลับไปเก็บผัก
- แตะแปลงที่ปลูกแต่ยังไม่รดน้ำเพื่อรดทันที แตะต้นที่กำลังโตไม่เริ่มเวลาใหม่
- แถบวัน/เลเวล/XP: เริ่มวันที่ 1, Lv.1, 0/100 XP; นับวันละ 24 ชั่วโมงจริงจากเวลาเริ่มสวน ไม่ใช่วันตามปฏิทิน/ฤดูกาล ปุ่มทดลอง +5 นาทีเพิ่มเฉพาะเวลาพืช
- ตัวเลือกดนตรี/เสียงเอฟเฟกต์/ลดการเคลื่อนไหวบันทึกในเครื่อง แยกจากเกม บัญชี และ cloud save; รีเซ็ตสวนหรือออกจากบัญชีไม่ล้างตัวเลือก
- ดนตรี pentatonic สังเคราะห์ต้นฉบับวน 12 วินาที และ 7 เสียง: ไถ ปลูก รดน้ำ เก็บเกี่ยว ซื้อขาย ส่งงาน และอัปเกรด ไม่มีไฟล์เสียงดาวน์โหลดหรือดนตรีจากเกมอื่น
- Native audio adapters: iOS AVAudioPlayer แบบ Ambient เคารพ silent switch/การหยุดแอป; Android MediaPlayer ผูก lifecycle และคืน resource เมื่อปิด ยังต้องตรวจเสียงบนมือถือจริง
- ภาพเคลื่อนไหวไถ/ปลูก/รดน้ำ/เก็บเกี่ยว แมวขยับและกะพริบตา ปุ่มตอบสนอง ตัวเลือก reduced motion หยุดการเคลื่อนไหวตกแต่งโดยยังเห็นสถานะเกม
- ขยายตัวหนังสือรองอย่างน้อย 13sp ปุ่มหลัก 16sp และปุ่มบวก/ลบ 52dp

## ความเข้ากันได้ของเซฟ

`schemaVersion` ยังเป็น 1 เพิ่ม metadata `startedAtMillis` แบบ optional เซฟเก่าที่ไม่มีค่านี้อ่านได้ตามเดิมและแสดงวันที่ 1 จนมีการบันทึกในเครื่องครั้งถัดไป ซึ่งจะตั้งเวลาเริ่มนับวันให้ ไม่รีเซ็ตเหรียญ พืช หรือเวลาเก็บเกี่ยว ตัวเลือกเสียงใช้ key/namespace แยก ไม่เพิ่มข้อมูลบัญชีหรือ token ลงในเซฟสวน

XP ยังมาจากคำสั่งซื้อตัวอย่างเพียงครั้งเดียวตาม PRD (20 XP) จึงยังไม่มีเนื้อหาหรือรางวัลจากเลเวลสูง ไม่สร้างงานซ้ำหรือฤดูกาลเพื่อให้ดูเป็นเกมเต็ม

## ตรวจแล้ว

- JVM unit tests 75 รายการ: GameEngine 13, SaveCodec 13, FarmProgress 2, GardenSession 24, GameFeedback 11, TradeModels 9, FarmMotion 3; failures/errors/skips เป็น 0
- Shared Compose semantics smoke: วงจรปลูกเดิม บัญชี Guest/โหมดบริการไม่พร้อม account-conflict fixture และ MVP fixture บนหน้าจอกว้าง 320dp
- MVP fixture ตรวจจำนวนซื้อ/ขาย ยอดรวม เงินไม่พอ ไม่เขียนเซฟเมื่อกด +/− กลับแปลงเดิม ราคาขาย รดน้ำทันทีไม่รีเซ็ต timer และตัวเลือกเสียงที่บันทึกแยกจากเซฟสวน
- Regression สำหรับกดทดลอง +5 นาทีแล้วบันทึกทันทีภายใน frame เดียวกัน: เซฟใช้ข้อมูลล่าสุด ไม่ย้อนเวลา/ข้อมูลกลับ; รอบสุดท้าย `jvmTest smokeUi` ผ่านใน 44 วินาที
- Render หน้าจอจริง 26 ภาพ (13 สถานะ × 393×852 และ 320×640) ตรวจหน้าฟาร์ม ร้าน ตั้งค่า เลือกเมล็ด และผลเก็บเกี่ยว; หน้าที่ยาวเลื่อนได้ ภาพอยู่ใน `verification/build/screenshots/`
- `:composeApp:compileKotlinIosSimulatorArm64 --offline` ผ่าน รวม shared UI/preferences และ iOS audio adapter; ไม่ได้ link framework หรือ `.app` ใหม่

## ทดลองบน Mac

`./scripts/gradle.sh -p verification playDesktop --offline --no-daemon --console=plain`

หน้าต่างระบุว่า “ทดลองบน Mac (ไม่ใช่ iOS)” ใช้ `App`/`GardenSession` จริงและ Guest save แบบ atomic ภายใต้ `.tooling/desktop-preview/guest-save.json` พร้อม preferences แยกไฟล์ ไม่อ่านเซฟมือถือ ไม่จำลองว่าล็อกอิน Google/Apple สำเร็จ JavaSound เล่นเสียงสังเคราะห์ชุดเดียวกับ native เมื่ออุปกรณ์พร้อม และพักเมื่อหน้าต่างเสีย focus/ย่อ

สั่งรัน `playDesktop` แล้ว process เริ่มและรายงานเส้นทางเซฟแยกโดยไม่มี error ใน log ที่ตรวจ แต่เครื่อง Mac ล็อกอยู่ จึงยังไม่ได้ตรวจหน้าต่างด้วย native UI automation หรือฟังเสียงจริง หลังผู้ใช้ปลดล็อกจึงตรวจการกด/การปิดแล้วเปิดต่อบนหน้าต่าง Mac ได้ ผล semantics smoke ข้างต้นไม่ใช่การยืนยันขั้นตอนนี้

## ยังไม่อ้างว่าผ่าน

- ยังไม่มี Simulator runtime; ยังไม่ทดสอบ iPhone/Android จริง รวม touch, safe-area, audio playback/interruption, background/resume และการเปิดแอปใหม่บนมือถือ
- Android source/APK ยังไม่ compile เพราะไม่มี Android SDK ที่ตั้งค่าพร้อม `.app` เดิมเป็นเวอร์ชันก่อนเปลี่ยนภาพและบัญชี
- Firebase project/config/provider ยังไม่มี ไม่ได้ดาวน์โหลด SDK เพิ่มหรือ deploy rules; OAuth, cloud save และ Firestore emulator ยังไม่ผ่านบริการจริง
- Soundtrack tests ตรวจโครงสร้าง WAV ความดังไม่ล้น และความคงที่ของข้อมูล ไม่ใช่การรับรองว่าเสียงเพราะหรือออกลำโพงบนมือถือจริง
- ยังไม่มีฤดูกาล เลี้ยงสัตว์ ความสัมพันธ์ NPC คราฟต์ งานหมุนเวียน multiplayer ระบบเงินจริง หรือเวลาฝั่ง server ป้องกันการโกงนาฬิกา
